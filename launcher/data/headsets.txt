# EternalVR launcher: headsets and their native panels, per eye (the Play tab's Headset box, Resolution's native panel).
# One headset per line: display name | identifiers | panel per eye WxH | refresh rates (Hz)
# Identifiers, separated by ';', tried in file order (the first headset with a match wins):
#   xr=  the OpenXR system name, exactly (a vendor's runtime names the model: Virtual Desktop, Meta Link, Pimax, Varjo)
#   vr=  SteamVR's headset model (steamvr.vrsettings, LastKnown HMDModel), exactly
#   vr~  a part of SteamVR's headset model, in any case
#   tk=  SteamVR's tracking system in its system name ("SteamVR/OpenXR : playstation_vr2"), in any case, and only for a
#        tracking system one headset alone uses: lighthouse (Index, Vive, Beyond...), oculus (Quest, Rift, Virtual
#        Desktop), aapvr (every Pimax), pico, vrlink and the like name no model and are never listed. SteamVR's last seen
#        model (vr=, vr~) wins over it when that model is in the list.
# Only identifiers seen in a real log, a vendor's source or a vendor's page are listed; a headset that matches none
# shows as not in the list rather than as a guess. ALVR reports the headset it imitates, so it is never matched.
# Panels and rates are the makers' figures (checked 2026-10-01). Order matters for the vr~ parts: a more specific
# name (Crystal Super, Crystal Light) comes before the one it contains.
