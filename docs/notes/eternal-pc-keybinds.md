# DOOM Eternal: default PC and gamepad bindings (Slayer)

- Sources: https://frondtech.com/doom-eternal-pc-keyboard-controls-and-key-bindings/ ;
  https://www.shacknews.com/article/117015/doom-eternal-controls-and-keybindings
- Fetched: 2026-09-25
- License: factual list compiled from the pages above (bindings are game facts; wording is ours).

Both sources agree on every keyboard/mouse row below. Gamepad column is from Shacknews only.
Rows marked [U] are not in either source and need confirming in the in-game
"Customize Slayer Keybinds" menu before the VR action map is frozen.

| Action | KB/M default | Gamepad (Xbox / PS) |
|---|---|---|
| Move forward / back / strafe | W / S / A / D | Left stick |
| Look | Mouse | Right stick |
| Jump (double jump in air) | Space | A / Cross |
| Dash | Left Shift | B / Circle |
| Fire | LMB | RT / R2 |
| Weapon mod (alt fire) | RMB | LT / L2 |
| Melee / Glory Kill (Blood Punch when charged) | E | RS click / R3 |
| Chainsaw | C | X / Square |
| Equipment Launcher (frag / ice) | Left Ctrl | LB / L1 |
| Flame Belch | R | Y / Triangle |
| Crucible (TAG2: Sentinel Hammer) | V | D-pad right |
| Switch weapon (tap) / weapon wheel (hold) | Q | RB / R1 |
| Switch weapon mod | F | D-pad up |
| Switch equipment | G | D-pad left |
| Next / previous weapon | Mouse wheel up / down | none |
| Combat Shotgun | 1 | none |
| Heavy Cannon | 2 | none |
| Plasma Rifle | 3 | none |
| Rocket Launcher | 4 | none |
| Super Shotgun (Meathook = its mod) | 5 | none |
| Ballista | 6 | none |
| Chaingun | 7 | none |
| BFG-9000 (Unmaykr shares slot?) [U] | 8 | none |
| Dossier (suit, weapons, codex, map, collectibles) | Tab | View / Touchpad [U] |
| Mission information / objective | Left Alt | [U] |
| Automap | inside Dossier [U] | [U] |
| Pause menu | Esc | Menu / Options |
| Push-to-talk (BATTLEMODE) | B | none |

Notes
- Other playable characters (BATTLEMODE demons; Revenant in the Fortress/Codex tutorial) use
  their own ability maps; out of scope for the first VR release.
- Game options also include hold-vs-toggle choices and weapon wheel behaviour [U];
  confirm names from the options menu.
